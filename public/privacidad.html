Política de privacidad

Esta política explica de forma sencilla cómo GStore usa los datos necesarios para recibir, confirmar y entregar pedidos realizados desde el catálogo.

Datos que podemos solicitar

  • Nombre, teléfono, correo electrónico, ciudad, dirección o referencia de entrega.
  • Productos elegidos, talla, color, cantidad, notas del pedido y método de entrega.
  • Estado del pedido, método de pago y datos técnicos básicos necesarios para seguridad del sitio.

Para qué usamos los datos

Usamos esta información para confirmar disponibilidad, coordinar entrega o retiro, registrar el pedido, atender consultas y mantener trazabilidad básica de compra.

Pagos y canales externos

Si PayPal está activo, el pago se procesa en PayPal. GStore no guarda datos completos de tarjetas. Si eliges WhatsApp, se abre una conversación externa para coordinar el pedido.

Conservación y seguridad

Los datos se conservan mientras sean necesarios para gestionar pedidos, soporte y registros comerciales. El panel administrativo no está enlazado desde la tienda y los datos sensibles se manejan desde backend o variables de entorno.

Derechos del cliente

Puedes pedir acceso, corrección o eliminación de tus datos por el mismo canal donde realizaste el pedido. La solicitud se revisará según la necesidad de conservar información para soporte, seguridad o registro comercial.

Actualizaciones

GStore puede actualizar esta política cuando cambien sus procesos de pedidos, pagos o entrega. La versión publicada en esta página será la vigente.
